## 🤖 What Each Hermes-Agent Does

### Hermes Agent Instance Configuration

**Base Model:** Kimi K2.6 via Orgo.ai  
**Deployment:** 1 instance per VM (lightweight, focused)  
**Runtime:** 24/7 in background  
**Daily Sync:** 09:00 AM Cape Town time (coordinated across all regions)

### Daily Workflow (Each Agent)

```
08:00 AM - Wake up, load context
          └─ Retrieve yesterday's notes from local Obsidian
          └─ Load client/partner data from database

08:15 AM - Morning Analysis Phase (45 min)
          ├─ Competitor research (what's happening in your market today?)
          ├─ Partner activity monitoring (who contacted you? what's new?)
          ├─ Customer/client needs analysis (what problems exist?)
          └─ Opportunity identification (3-5 highest-value opportunities)

09:00 AM - Sync to Central Brain (15 min)
          ├─ Send daily report to Obsidian
          ├─ Receive instructions from Natalia (if any)
          └─ Coordinate with other agents on shared initiatives

09:15 AM - Action Phase (4 hours)
          ├─ Create pitch documents (custom for today's opportunities)
          ├─ Generate email/message templates for outreach
          ├─ Research client/prospect details
          └─ Prepare sales/support materials for human team

13:30 PM - Handoff to Humans
          └─ Report ready for human execution (calls, meetings, emails)

17:00 PM - Evening Update
          ├─ Track outcomes from human activities
          ├─ Update opportunity status
          ├─ Log new information discovered
          └─ Prepare notes for tomorrow's analysis

20:00 PM - Final Sync (if needed)
          └─ Update Obsidian with daily outcomes
          └─ Flag issues needing Natalia attention
```

## 💻 Technical Implementation

### Agent Deployment per VM

**Dockerfile (Hermes Agent):**
```dockerfile
FROM ubuntu:20.04

# Install dependencies
RUN apt-get install -y python3.10 node.js docker.io

# Install Hermes CLI
RUN npm install -g hermes-agent

# Install Ollama (for local model inference)
RUN curl https://ollama.ai/install.sh | sh

# Create agent config
COPY hermes-agent.config.yaml /etc/hermes/
COPY obsidian-sync.sh /usr/local/bin/

# Configure systemd service
COPY hermes-agent.service /etc/systemd/system/

# Enable and start
RUN systemctl enable hermes-agent

EXPOSE 8443
CMD ["hermes-agent", "start"]
```

**Daily Sync Script (`obsidian-sync.sh`):**
```bash
#!/bin/bash

# Run at 9:00 AM daily

# 4. Updates local config with new directives
# 5. Logs timestamp & confirmation
```
